1. Latar Belakang & Tujuan Implementasi

Penelitian dan eksperimen penambangan web (Web Mining) sering kali hanya berhenti pada tahap analisis statistik di dalam notebook atau perangkat lunak desktop (seperti Orange Data Mining). Padahal, nilai utilitas tertinggi dari suatu model pembelajaran mesin terletak pada kemampuannya memberikan inferensi secara waktu-nyata (real-time inference) terhadap data baru yang belum pernah dilihat sebelumnya.

Oleh karena itu, seluruh rangkaian tahapan dari proyek tugas ini — mulai dari Pengumpulan Data (Crawling), Pra-pemrosesan Teks, Ekstraksi Representasi Vektor Skip-Gram, hingga Pelatihan Model Klasifikasi — diintegrasikan menjadi satu kesatuan produk perangkat lunak berbasis web interaktif.

2. Alur Arsitektur Inferensi (Pipeline)

Ketika pengguna memasukkan URL artikel berita Detik.com ke dalam aplikasi web, sistem mengeksekusi 5 tahapan komputasi berurutan secara otomatis:

Diagram Alir Pemrosesan Prediksi:

  1. Pengunduhan & Ekstraksi Konten (Trafilatura): URL diunduh secara live via HTTP. Algoritma Trafilatura secara otomatis mengisolasi teks berita inti dan membuang elemen non-konten (iklan, navigasi menu, widget rekomendasi, dan kolom komentar).
  2. Pra-pemrosesan & Tokenisasi (Regex): Teks artikel dibersihkan dari tanda baca dan kata-kata tidak baku (slang removal). Pembersihan disesuaikan dengan varian yang dipilih:
    • Versi 1 (Dengan Angka): Menggunakan ekspresi reguler \b\w+\b.
    • Versi 2 (Tanpa Angka): Menggunakan ekspresi reguler \b[a-zA-Z]+\b.
  3. Agregasi Fitur Dokumen (Mean Pooling 100D): Setiap token kata dicari koordinat vektor bobotnya di dalam model Skip-Gram (model_sg.wv[kata]). Seluruh vektor kata dijumlahkan dan dirata-ratakan menjadi satu vektor dokumen tunggal berdimensi 100.
  4. Inferensi Algoritma Klasifikasi: Vektor dokumen 100 dimensi dimasukkan ke dalam model klasifikasi terpilih (kNN berbasis jarak Euclidean atau Gaussian Naive Bayes berbasis probabilitas kontinu) yang telah dimuat dari berkas .joblib.
  5. Visualisasi Hasil & Metrik Evaluasi: Antarmuka menampilkan label kategori terpilih (⚽ Sport atau 💰 Finance) lengkap dengan 6 metrik performa model (AUC, Akurasi CA, F1-Score, Precision, Recall, MCC) berdasarkan hasil pengujian empiris data uji di Orange Data Mining.

3. Fitur Unggulan Aplikasi

⚡ Real-time Web Scraping Tanpa Copy-Paste Manual

Pengguna tidak perlu menyalin dan menempelkan ratusan kata dari portal berita secara manual. Cukup masukkan link URL artikel Detik.com, sistem akan membaca dan mengekstrak judul, tanggal publikasi, serta seluruh badan artikel secara otomatis.

🎛️ Fleksibilitas Pemilihan Dua Varian Preprocessing

Melalui panel sidebar, pengguna dapat secara bebas menguji perbedaan perilaku inferensi antara Versi 1 (Dengan Angka) dan Versi 2 (Tanpa Angka) untuk mengamati langsung bagaimana kehadiran angka mempengaruhi koordinat representasi dokumen.

🤖 Pemilihan Algoritma Machine Learning

Menyediakan opsi perbandingan antara algoritma k-Nearest Neighbors (kNN) dengan $k=5$ tetangga terdekat berbobot metrik Euclidean, serta algoritma Gaussian Naive Bayes.

📊 Kartu Metrik Evaluasi Komprehensif

Di bawah hasil prediksi, aplikasi menyajikan 6 kartu metrik terukur yang diperoleh dari pengujian Test on test data (160 Data Latih / 40 Data Uji) di Orange Data Mining:

  • AUC (Area Under ROC Curve): Mengukur ketajaman model dalam membedakan kedua kelas secara menyeluruh.
  • CA (Classification Accuracy): Persentase kebenaran klasifikasi terhadap seluruh data uji.
  • F1-Score, Precision, & Recall: Evaluasi keseimbangan prediksi kelas positif dan negatif.
  • MCC (Matthews Correlation Coefficient): Koefisien korelasi kualitas prediksi biner bahkan pada kondisi data yang paling ketat.

4. Panduan Pengujian untuk Penguji / Dosen

Untuk mendemonstrasikan keandalan sistem klasifikasi, Anda dapat mengikuti langkah-langkah pengujian berikut secara langsung pada aplikasi:

Langkah 1: Buka portal berita Detik.com (kanal sport.detik.com atau finance.detik.com).
Langkah 2: Salin (copy) link URL salah satu artikel berita aktif.
Langkah 3: Tempelkan (paste) link tersebut pada kolom "Masukkan Link URL Berita" di aplikasi.
Langkah 4: Tentukan kombinasi varian Skip-Gram dan algoritma di sidebar, lalu klik tombol "🚀 Klasifikasikan Berita".
