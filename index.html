Pengantar Web Mining

Web mining adalah penerapan teknik data mining untuk menemukan dan mengekstrak pola, informasi, serta pengetahuan yang berguna dari data berbasis web. Secara umum, web mining dibagi menjadi tiga kategori utama:

  • Web Content Mining: Ekstraksi data dari isi dokumen web (teks, gambar, audio, dll).
  • Web Structure Mining: Analisis struktur keterhubungan antar halaman melalui hyperlink.
  • Web Usage Mining: Analisis data log dan riwayat aktivitas pengguna saat menjelajahi web.
