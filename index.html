1. Konsep Dasar Web Mining

Web Mining didefinisikan sebagai pemanfaatan teknik data mining secara otomatis untuk menemukan, mengekstraksi, dan memahami pola serta informasi tersembunyi dari dokumen, layanan, dan repositori World Wide Web (Liu, 2011).

Web merupakan ekosistem data yang sangat besar, heterogen, dinamis, dan sebagian besar bersifat tidak terstruktur (unstructured data). Karakteristik inilah yang membedakan Web Mining dari data mining konvensional yang umumnya beroperasi pada basis data terstruktur (relasional).

2. Taksonomi Web Mining

Berdasarkan literatur ilmiah (Kosala & Blockeel, 2000), Web Mining diklasifikasikan ke dalam tiga domain utama:

A. Web Content Mining (WCM)

Fokus pada penambangan dan ekstraksi informasi dari konten nyata halaman web (berupa teks terstruktur/tak terstruktur, gambar, audio, maupun video). Bidang ini mengintegrasikan teknik Natural Language Processing (NLP), Information Retrieval (IR), serta klasifikasi dan klasterisasi teks.

B. Web Structure Mining (WSM)

Menganalisis topologi hubungan dan skema keterkaitan antar dokumen web melalui representasi hyperlink. Dua algoritma paling fundamental pada kategori ini adalah PageRank (Brin & Page) dan HITS (Kleinberg), yang mengukur otoritas serta popularitas suatu halaman berdasarkan graf tautannya.

C. Web Usage Mining (WUM)

Meneliti jejak interaksi pengguna dengan server web. Data utamanya bersumber dari riwayat log server (server access logs), sesi interaksi, registrasi, dan clickstream. Tujuannya meliputi analisis perilaku pengguna, personalisasi konten, dan sistem rekomendasi (Cooley et al., 1999).

3. Siklus Proses Web Mining

Secara umum, proses penambangan web melibatkan alur sistematis berikut:

  1. Pengumpulan Sumber Data (Data Gathering): Crawling dan scraping dokumen dari internet.
  2. Pra-pemrosesan Data (Preprocessing): Pembersihan tagging HTML, tokenisasi kata, filtering (stopword removal), stemming, serta parsing log.
  3. Penerapan Algoritma (Pattern Discovery): Penggunaan algoritma asosiasi, klasifikasi, regresi, atau klasterisasi.
  4. Evaluasi & Interpretasi (Pattern Analysis): Validasi pola yang ditemukan untuk menarik kesimpulan yang relevan bagi pengambilan keputusan.
